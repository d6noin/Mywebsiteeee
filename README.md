# Досье — сайт для GitHub Pages

Минималистичная тёмная визитка в стиле «карточки досье»: аватар справа, блок «Досье»
с произвольными полями (метка → значение) и отзывы. Посты и новости убраны.

## Как залить на GitHub Pages

1. Создай репозиторий на GitHub (например `gosha` или `username.github.io`).
2. Загрузи файлы:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `data.json`
   - `ss.jpg` ← твоя основная аватарка
   - папка `avatars/` (1.jpg…6.jpg) ← галерея аватарок на выбор
3. Settings → Pages → Source: `Deploy from a branch` → `main` / `/ (root)`.
4. Через 1–2 минуты сайт будет доступен по адресу вида
   `https://ТВОЙ_НИК.github.io/ИМЯ_РЕПО/`.

## Как теперь работают данные — важно!

GitHub Pages отдаёт статичные файлы, поэтому «Досье», ник, описание и аватар
хранятся в файле **`data.json`** — это единственная версия, которую видят
**все** посетители сайта.

Когда ты (как админ) что-то меняешь через «настройки» или «+ запись» — это
сначала сохраняется только у тебя в браузере, как черновик. Чтобы изменения
увидели остальные:

1. Нажми **«опубликовать»** в шапке сайта.
2. Откроется готовый JSON — нажми **«Скачать data.json»**.
3. Загрузи скачанный файл в свой репозиторий на GitHub, заменив старый
   `data.json` (Add file → Upload files → Commit), или открой файл на GitHub
   и вставь текст вручную.
4. Через 1–2 минуты GitHub Pages пересоберёт сайт — все увидят новые данные.

**Отзывы от гостей** — та же история: когда кто-то оставляет отзыв, он
сохраняется только у него в браузере (сайт честно предупреждает об этом
в форме). Если хочешь опубликовать чей-то отзыв — попроси прислать текст и
добавь его сам через «+ запись» в разделе «Досье» или впиши прямо в
`data.json` в массив `reviews` вручную перед коммитом.

## Аватар

- Можно вписать прямую ссылку/имя файла в поле «своя ссылка».
- Или выбрать из **галереи** — 6 картинок-плейсхолдеров уже лежат в
  `avatars/1.jpg`…`avatars/6.jpg`. Просто замени их своими файлами с теми же
  именами, и они появятся в галерее выбора в настройках.
- Список файлов галереи можно расширить/поменять в начале `script.js`,
  массив `AVATAR_GALLERY`.

## Палитра

Чёрный фон, красный и синий акценты. Моноширинный шрифт (JetBrains Mono) —
всё оформлено как карточка/запись в базе данных, без лишних декораций.
