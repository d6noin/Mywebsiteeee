# Досье — сайт для GitHub Pages

Минималистичная тёмная визитка в стиле «карточки досье»: аватар справа, блок «Досье»
с произвольными полями (метка → значение) и отзывы. Посты и новости убраны.

## Как залить на GitHub Pages

1. Создай репозиторий на GitHub (например `gosha` или `username.github.io`).
2. Загрузи файлы:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `ss.jpg` ← положи сюда свою аватарку (квадратная картинка смотрится лучше всего)
3. Settings → Pages → Source: `Deploy from a branch` → `main` / `/ (root)`.
4. Через 1–2 минуты сайт будет доступен по адресу вида
   `https://ТВОЙ_НИК.github.io/ИМЯ_РЕПО/`.

## Пароль админа

По умолчанию: **`12312345`**

Сменить — в `script.js`, в самом верху:
```js
const ADMIN_PASSWORD = 'твой_новый_пароль';
```

После входа (кнопка «вход» в верхней панели) появляются:
- **настройки** — ник, описание, аватар, номер записи (REC №), статус и его цвет
- **+ запись** — добавить произвольное поле в «Досье» (метка + значение, можно
  сколько угодно: город, телеграм, род занятий, контакты и т.д.)
- у каждой записи и отзыва появляется «×» для удаления

## Данные

Всё хранится в **localStorage** браузера — данные видны только в том браузере,
где их создали. Для общего доступа с разных устройств нужен бэкенд.

## Палитра

Чёрный фон, красный и синий акценты. Моноширинный шрифт (JetBrains Mono) —
всё оформлено как карточка/запись в базе данных, без лишних декораций.
